# AI エージェント連携

ターミナルパネルで動かす AI エージェント（Claude Code など）と、gh-editor の間で情報をやりとりします。

## 現在の文脈をエージェントへ送る

次のどれかで実行します。

- `Space a`（Helix モード）
- `Alt+A`
- コマンドパレット

選択範囲（選択がなければカーソルの行）を、次の形に整えます。

1. `パス:開始行-終了行`
2. 選択した本文（コードブロック）
3. その行にかかる診断（エラー・警告など）

整えた文はプレビューに出ます。

| キー | 動作 |
| --- | --- |
| `Enter` | ターミナルパネルに貼り付ける（`Enter` は送らない） |
| `Esc` / `q` | やめる |
| `j` / `k` | プレビューをスクロール |

- 保存済みのファイルでだけ使えます。
- 200 行を超える部分は省略します。

## レビューコメントを送る

ローカルの変更のレビューで書いたコメントを、エージェントに渡せます。
手順は [レビュー](review.md) にあります。

## シェルから gh-editor を操作する

gh-editor は起動すると Unix ソケット（権限 0600）を作ります。
ソケットの場所は、ターミナルパネルのシェルの環境変数 `GH_EDITOR_SOCKET` に入ります。
そのシェルで次のコマンドが使えます。

| コマンド | 動作 |
| --- | --- |
| `gh-editor open <パス>[:行]` | ファイルを開く。`:行` を付けるとその行へ移動 |
| `gh-editor diff [パス]` | ローカルの変更のレビューを開く。パスを付けるとそのファイルの差分 |
| `gh-editor status` | ルート、ブランチ、開いているタブ、カーソルの行を JSON で表示 |

## スキルを書き出す

```sh
gh-editor skill install [書き出し先]
```

上のコマンドの使い方を書いたスキル（`SKILL.md`）を書き出します。
書き出し先を省略すると `~/.claude/skills/gh-editor/` に書きます。
Claude Code はこのスキルを読んで、ファイルや差分を gh-editor で開けるようになります。
