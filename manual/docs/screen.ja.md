# 画面の見方

画面は VS Code と同じ並びです。

| 場所 | 中身 | 表示の切替 |
| --- | --- | --- |
| 左 | ファイルツリー | `Ctrl+B` |
| 上 | タイトル行（開いているファイルのパス。未保存なら ●） | — |
| 中央 | エディタ、プレビュー、ブラウザなど開いているファイルの中身 | — |
| 下 | ターミナルパネル | ``Ctrl+` `` |
| 右 | 提案パネル（[AI エージェント連携](agent.md)） | `Alt+I` |
| 最下段 | ステータスバー | — |

[差分モード](review.md)の間は、一番上にヘッダー、ステータスバーの上にヘルプ行が増えます。

## フォーカスの移動

- `Ctrl+E`：ファイルツリーとエディタの間でフォーカスを移します。
- `Space e`（Helix モード）：ファイルツリーへ移ります。
- `Space E`（Helix モード）：差分モードのとき、CHANGES へ移ります。差分モードでないときは、ファイルツリーへ移ります。
- ファイルツリーで `Esc`：エディタへ戻ります。
- `Alt+I`（Helix モードでは `Space i` も）：提案パネルへ移ります。もう一度押すと閉じます。
- マウスでクリックした場所にもフォーカスが移ります。

## ステータスバー

左から順に、次を表示します。

1. モード（Helix モードでエディタにフォーカスがあるとき）：`NOR`（ノーマル）、`INS`（挿入）、`SEL`（選択）。`Space` などを押した途中のキーも並べて表示します。
2. Git のブランチ名（`⎇ main` の形）
3. フォーカスがエディタ以外のとき、その場所の名前（「ファイルツリー」「ターミナル」「提案パネル」）
4. 診断の数（`● エラーの数  ▲ 警告の数`）
5. 提案パネルを出していないときの提案の数（`提案 N（Alt+I）`）

右には、次を表示します。

1. カーソルの位置（`行:列`）。マルチカーソルのときはカーソルの数。選択中は選択した文字数
2. インデント（`スペース: 4` または `タブ`）
3. 言語名と LSP の状態

## ペインの大きさを変える

`Alt+R` でリサイズモードに入ります。

| キー | 動作 |
| --- | --- |
| `←` / `→`（`h` / `l`） | フォーカスのあるペインの左右の境界を、左 / 右へ 2 列動かす |
| `↑` / `↓`（`k` / `j`） | フォーカスのあるペインの上下の境界を、上 / 下へ 2 行動かす |
| `<` / `>` | エディタとプレビューの境界 |
| `=` | 初期値に戻す |
| `Esc` | リサイズモードを終わる |

矢印キーで動く境界は、フォーカスのあるペインで決まります。

| フォーカスのあるペイン | `←` / `→` | `↑` / `↓` |
| --- | --- | --- |
| エクスプローラ / CHANGES | サイドバーの右端 | 差分モードでは、エクスプローラと CHANGES の境界。それ以外ではターミナルの上端 |
| エディタ | 差分の分割表示では、左右の境界の `│`。それ以外では、プレビューか提案パネルとの境界。どちらも無ければサイドバーの右端 | ターミナルの上端 |
| ターミナル | サイドバーの右端 | ターミナルの上端 |
| 提案パネル | 提案パネルの左端 | ターミナルの上端 |

境界線をマウスでドラッグしても変えられます。
差分モードでは、エクスプローラと CHANGES の境界（CHANGES の見出しの行）をドラッグすると、上下の高さの比率を変えられます。どちらも 3 行より小さくはなりません。`=` で 7:3 に戻ります。端末の高さを変えても比率は保たれます。
大きさは、shijimi を終了するまで保たれます。

## ファイルの切替

タブバーはありません。開いたファイルは一覧に残り、今のファイルだけを表示して、タイトル行にそのパスを出します。

| キー | 動作 |
| --- | --- |
| `Space b`（Helix モード）/ Quick Open | 開いたファイル / 任意のファイルから選ぶ |
| `ga`（Helix モード）/ `Ctrl+Tab` | 直前に開いていたファイルと今のファイルを行き来 |
| `Ctrl+O` / `Ctrl+I` | ジャンプの元へ戻る / 進む |
| `Ctrl+W` | 今のファイルを閉じる（一覧から外す） |

`Ctrl+Tab` は kitty keyboard protocol に対応した端末でだけ shijimi に届きます。そうでない端末では `ga` か `Space b` を使ってください。

## コマンドパレット

`F1` または `Ctrl+K`（Helix モードでは `Space ?` も）でコマンドパレットを開きます。
名前の一部を入力して、実行したい操作を選びます。キーを覚えていない操作もここから実行できます。
