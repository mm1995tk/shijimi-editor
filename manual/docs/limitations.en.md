# Limitations

These are the known limitations.

- Images and mermaid diagrams can be displayed only in terminals that support the Kitty graphics protocol (Kitty / Ghostty / WezTerm and so on).
- There is no built-in browser for showing web pages. Open them in an external browser ([External browser and port forwarding](browser.md)).
- In diff mode, you cannot yet send comments or reviews to a pull request.
- Comparing with the base of a pull request requires `gh` and `gh auth login`.
