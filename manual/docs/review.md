# レビュー

2 種類のレビューがあります。

| 種類 | 開き方 | 必要なもの |
| --- | --- | --- |
| プルリクエストのレビュー | `Space g`（一覧）、`:pr`（一覧）、`:pr <番号>` | `gh`（`gh auth login` 済み） |
| ローカルの変更のレビュー | `Space G`、`Ctrl+G`、`:review` | `git` |

ローカルの変更のレビューは、`git diff HEAD` と未追跡のファイルを表示します。

## 画面

左にファイルの一覧、右に差分を表示します。

## キー操作

| キー | 動作 |
| --- | --- |
| `j` / `k` | 移動 |
| `]` `n` / `[` `p` | 次 / 前のハンク |
| `J` / `K` | 次 / 前のファイル |
| `Ctrl+D` / `Ctrl+U` | 1 画面下 / 上 |
| `g` / `G` | 先頭 / 末尾 |
| `Tab` / `h` / `l` | ファイルの一覧と差分の間でフォーカスを移す |
| `s` | 左右分割と 1 列の切替 |
| `v` | 確認済みにする（次のファイルへ進む）。もう一度押すと戻る |
| `c` | この行にコメント（`\n` で改行） |
| `d` / `x` | 未送信のコメントを削除 |
| `y` | コメントを Markdown でコピー |
| `a` | コメントをエージェントへ送る（プレビューで確認してから） |
| `Enter` / `o` | ファイルをエディタで開く |
| `A` / `R` / `S` | 承認 / 変更を要求 / コメントのみ、で送信（プルリクエストのみ） |
| `C` | `gh pr checkout` を実行（プルリクエストのみ） |
| `r` | 再読み込み |
| `q` / `Esc` | 閉じる |

## プルリクエストにレビューを送る

1. 差分の行に移動して `c` を押し、コメントを書きます。必要な数だけ繰り返します。
2. `A`（承認）、`R`（変更を要求）、`S`（コメントのみ）のどれかを押します。
3. 本文を入力して確定します。未送信のコメントもまとめて送ります。

`R` と `S` では、本文かコメントのどちらかが必要です。

## ローカルの変更へのコメントをエージェントに渡す

ローカルの変更のレビューは GitHub に送れません。代わりに、コメントを AI エージェントに渡します。

- `y`：コメントを Markdown でクリップボードにコピーします。
- `a`：プレビューを開きます。`Enter` でターミナルパネルに貼り付けます。詳しくは [AI エージェント連携](agent.md) にあります。
