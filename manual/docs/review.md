# レビュー

2 種類のレビューがあります。

| 種類 | 開き方 | 必要なもの |
| --- | --- | --- |
| プルリクエストのレビュー | `Space g`（一覧）、`:pr`（一覧）、`:pr <番号>` | `gh`（`gh auth login` 済み） |
| 変更の確認（git-diff モード） | `Space G`、`Ctrl+G`、`:gitdiff` | `git` |

## git-diff モード

エディター全体を「通常モード」と「git-diff モード」で切り替えます。
`Ctrl+G`（Helix モードでは `Space G`）、`:gitdiff`、コマンドパレットで入ります。もう一度実行すると通常モードに戻ります。

- サイドバーが上下 7:3 に分かれ、下の 3 に **CHANGES**（変更ファイルの一覧）が出ます。`Tab` でファイルツリーと行き来します。
- 変更のないファイルは、通常のエディターで開きます。
- 変更のあるファイルは、ファイル全体を **Split**（左が比較元、右が今のファイル）で開きます。
- 新規ファイル（未追跡を含む）は、全行を追加行の色で表示します。
- 右側（今のファイル）は、通常どおり編集・保存できます。編集すると diff がすぐに更新されます。
- CHANGES の一覧は、保存したとき、外部の変更を検知したとき、数秒ごとに更新します。

### Split と Unified

`s`、`:gitdiff split`、`:gitdiff unified`、ヘッダーの `[分割 ⇄ 統合]` のクリックで切り替えます。
Unified でも編集できます。削除された行は、読み取り専用の行として挟まります。

### 比較元（base）

`b` または `:gitdiff base head|pr` で切り替えます。

| 比較元 | 内容 |
| --- | --- |
| `HEAD`（初期値） | `HEAD` と作業ツリーを比べる。未追跡ファイルを含む |
| PR の base | 今のブランチに PR があるとき、`git merge-base <PR の base> HEAD` と作業ツリーを比べる |

PR の base を選ぶと、GitHub の PR 画面の差分に、まだコミットしていない変更を足したものになります。
base ブランチをマージしても、差分には自分の変更だけが出ます。この比較には `gh` が必要です。

### CHANGES のキー操作

| キー | 動作 |
| --- | --- |
| `j` / `k` | 移動 |
| `Enter` / `l` | ファイルを開く |
| `s` | 分割 / 統合の切替 |
| `b` | 比較元の切替（`HEAD` ⇄ PR の base） |
| `r` | 一覧の更新 |
| `Tab` | ファイルツリーへ |
| `Esc` | エディタへ |

## プルリクエストのレビュー

左にファイルの一覧、右に差分を表示します。

| キー | 動作 |
| --- | --- |
| `j` / `k` | 移動 |
| `]` `n` / `[` `p` | 次 / 前のハンク |
| `J` / `K` | 次 / 前のファイル |
| `Ctrl+D` / `Ctrl+U` | 1 画面下 / 上 |
| `g` / `G` | 先頭 / 末尾 |
| `Tab` / `h` / `l` | ファイルの一覧と差分の間でフォーカスを移す |
| `s` | 左右分割と 1 列の切替 |
| `v` | 確認済みにする（次のファイルへ進む）。もう一度押すと戻る |
| `c` | この行にコメント（`\n` で改行） |
| `d` / `x` | 未送信のコメントを削除 |
| `y` | コメントを Markdown でコピー |
| `a` | コメントをエージェントへ送る（プレビューで確認してから） |
| `Enter` / `o` | ファイルをエディタで開く |
| `A` / `R` / `S` | 承認 / 変更を要求 / コメントのみ、で送信 |
| `C` | `gh pr checkout` を実行 |
| `r` | 再読み込み |
| `q` / `Esc` | 閉じる |

### プルリクエストにレビューを送る

1. 差分の行に移動して `c` を押し、コメントを書きます。必要な数だけ繰り返します。
2. `A`（承認）、`R`（変更を要求）、`S`（コメントのみ）のどれかを押します。
3. 本文を入力して確定します。未送信のコメントもまとめて送ります。

`R` と `S` では、本文かコメントのどちらかが必要です。

### コメントをエージェントに渡す

`y` でコメントを Markdown としてクリップボードにコピーできます。
`a` を押すとプレビューが開き、`Enter` でターミナルパネルに貼り付けます。詳しくは [AI エージェント連携](agent.md) にあります。
