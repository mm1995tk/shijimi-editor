# ファイルと検索

## ファイルを開く

| 方法 | 動作 |
| --- | --- |
| `Ctrl+P`（Helix モードでは `Space f` も） | Quick Open。ファイル名の一部を入力して選ぶ |
| `Space b`（Helix モード） | 開いているバッファの一覧から選ぶ |
| `:o <パス>` | パスを指定して開く |
| `Ctrl+N` / `:n` | 名前のない新しいファイル |
| ファイルツリーで `Enter` | 選んだファイルを開く |

## 保存

| 方法 | 動作 |
| --- | --- |
| `Ctrl+S` / `:w` | 保存 |
| `:w <パス>` | 別のパスに保存 |
| `:wa` | すべて保存 |

**自動保存**が既定で有効です。編集が 1 秒止まると保存します。名前のないファイルは対象外です。
無効にする方法は [設定ファイル](config.md) にあります。

## ファイルツリー

`Ctrl+B` で表示を切り替えます。`Ctrl+E` でフォーカスを移します。

| キー | 動作 |
| --- | --- |
| `j` / `k` | 下 / 上へ移動 |
| `Ctrl+D` / `Ctrl+U` | 1 画面下 / 上 |
| `g` / `G` | 先頭 / 末尾 |
| `Enter` / `o` | ファイルを開いてエディタへ移る。フォルダーは開閉 |
| `l` | ファイルを開く（フォーカスはツリーのまま）。フォルダーは展開 |
| `h` | フォルダーを閉じる。閉じていれば親フォルダーへ |
| `a` / `n` | 新しいファイル |
| `A` / `N` | 新しいフォルダー |
| `r` | 名前の変更 |
| `d` / `Delete` | 削除 |
| `R` | ツリーを更新 |
| `Esc` / `q` / `Tab` | エディタへ戻る |

### Git の状態の表示

| 文字 | 意味 |
| --- | --- |
| `M` | 変更あり |
| `U` | 未追跡 |
| `A` | 追加済み（ステージ済み） |
| `D` | 削除 |
| `R` | 名前の変更 |
| `•` | 中に変更のあるファイルを含むフォルダー |

## ファイル内の検索

| 方法 | 動作 |
| --- | --- |
| `/` / `?`（Helix モード） | 前方 / 後方へ検索。`n` / `N` で次 / 前 |
| `Ctrl+F`（VS Code モード） | 検索欄を開く。選択中の文字（1 行以内）が初期値になる |

## プロジェクト全体の検索

`Space /`（Helix モード）か `:grep <文字列>` で検索します。
結果の一覧から選ぶと、その行を開きます。

- `rg`（ripgrep）があれば使います。無ければ `git grep` を使います。
- `-x` で除外、`-i` で包含する glob を指定します。カンマで区切ると複数指定できます。

```text
:grep -x '*.lock,dist/**' -i '*.go' foo
```

`-x` は `--exclude=`、`-i` は `--include=` とも書けます。

常に効かせたい指定は `[search]` に書きます。

```toml
[search]
exclude = ["*.lock", "dist/**"]
include = []
```

!!! warning "書く場所"
    `[search]` は `~/.config/gh-editor/config.toml` か `.gh-editor/config.toml` に書きます。
    `.helix/config.toml` に書くと、Helix が未知のセクションとして拒否します。

## プロジェクト全体の置換

`:replace <文字列> => <置換後>` で、プロジェクト全体を置換します。

1. `:replace foo => bar` を実行します。差分のプレビューがタブで開きます。
2. `j` / `k` で移動します。
3. 除外したい行で `x` を押します。ファイルの行で押すと、ファイルごと除外します。もう一度押すと元に戻ります。
4. `Enter` で置換します。`q` で何もせずに閉じます。

- 検索は文字列そのままです（正規表現ではありません）。
- 検索する文字列が小文字だけなら、大文字と小文字を区別しません。
- `-x` / `-i` は `:grep` と同じです。
- 置換したファイルはバッファとして開きます。保存するまでディスクは変わりません。`u` / `Ctrl+Z` で元に戻せます。

## 外部での変更の反映

AI エージェントなど、別のプロセスがファイルを変えると、gh-editor は自動で読み直します。

- 未保存の編集があるファイルは読み直しません。`:reload` を実行すると読み直します。
- 無効にするには `[editor]` の `watch-files = false` を設定します（[設定ファイル](config.md)）。
