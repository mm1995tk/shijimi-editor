# 外部ブラウザとポート転送

ターミナルの UI に、ブラウザは入っていません。Web ページは、手元のブラウザで開きます（GUI にはブラウザの欄があります。下の「GUI のブラウザの欄」）。リモートの VM で動かしている開発サーバーは、ポート転送して手元のブラウザで見ます（下の「リモートの VM で使う例」）。

## 外部ブラウザで開く

- `Space o`（Helix モード）：カーソル位置の URL を開きます。
- `:open-url [URL]`：URL を開きます。省略するとカーソル位置の URL を開きます。

Linux では `xdg-open`、macOS では `open` を使います。


## GUI のブラウザの欄

GUI では、ページをターミナルの隣に出せます。窓を離れずに済みます。GUI のワークスペースのプライマリターミナルで動く shijimi-editor で `:open-url <URL>`（URL の上で `Space o`）を実行すると、そのマシンのブラウザは呼ばず、GUI がターミナルの隣にブラウザの欄を開きます。インターネットのページも、ワークスペースがあるマシンの開発サーバーも見られます。

- 開けるのは `http` と `https` のアドレスだけです。欄には戻る・進む・再読み込み・アドレス欄・外部ブラウザで開き直すボタン（↗）・閉じるボタン（×）があります。アドレス欄に `localhost:3000` のように打つと補います（自分のマシンなら `http://`、ほかは `https://`）。
- ページは、欄の上に重ねた専用の web view に出します。多くのサイトはフレームの中に出されるのを断るためです。web view は GUI 自身のカードより上に出るので、カード（ssh の質問など）が出ているあいだと、欄を出していないあいだは隠します。
- ページから GUI の API は呼べません。GUI は、インターネットのどのアドレスにも権限を渡しません。
- **リモートのマシンの開発サーバー**（`localhost`・`127.0.0.1`・`[::1]`・`0.0.0.0`）：GUI がそのマシンへ欄のために `ssh -N -L` を張り、そこを通してページを開きます。アドレス欄には `localhost:<ポート>` のまま出ます。ssh のパスワードを GUI で聞かれることがあります。転送は欄を閉じると止まります。マシン自身ではないアドレス（`https://example.com` など）は、手元から開きます。
- 欄はターミナルの欄と同じ升目の 1 つです（1 つのワークスペースに 6 個まで）。タブにはしません。ブラウザの欄はワークスペースに 1 つで、別の URL を開くと入れ替わります。URL を開くと欄が出て（ほかの欄を隠していても）、キーは欄の枠に移るので、GUI のキー（`Ctrl+Shift+矢印` など）が効きます。ページを操作するにはページを押します。キーがページにあるあいだは、ページの外を押すと GUI のキーに戻ります。
- ほかのワークスペースへ切り替えるとページは閉じ、戻ると最初のアドレスから開き直します。
- ターミナルの中のリンクは、まだこの欄では開きません。

## ポート転送

`:browser forward <対象ポート> [待ち受けポート]` を実行すると、shijimi が `127.0.0.1` で待ち受け、`localhost:<対象ポート>` へ TCP で転送します。
HTTP も WebSocket も通ります。

| コマンド | 動作 |
| --- | --- |
| `:browser forward <対象ポート> [待ち受けポート]` | 転送を始める。待ち受けポートを省略すると、空いているポートを選ぶ |
| `:browser list` | 転送の一覧 |
| `:browser stop <待ち受けポート>` | 転送を止める |

shijimi を終了すると、すべての転送が止まります。

### リモートの VM で使う例

VM で shijimi を動かし、開発サーバーを手元のブラウザで見る手順です。

1. VM の shijimi で `:browser forward 3000` を実行します。表示された待ち受けポートを控えます。
2. 手元で次を実行します。

    ```sh
    ssh -L 8080:127.0.0.1:<待ち受けポート> vm
    ```

3. 手元のブラウザで `http://localhost:8080` を開きます。

直接 `ssh -L` するのに比べて、次の利点があります。

- 待ち受けポートを固定できます。
- `0.0.0.0` や IPv6 だけで待ち受けるサーバーも、`127.0.0.1` で受けられます。

この 2 つが不要なら、`ssh -L` を直接使ってください。

### 待ち受けアドレス

```toml
[browser]
listen-host = "127.0.0.1"
```

既定は `127.0.0.1` です。`0.0.0.0` に変えるのは、信頼できるネットワークの中だけにしてください。

### ブラウザの欄の制限

- リモートのマシンのページの中のリンクやリダイレクトが、絶対アドレスの `http://localhost:<ポート>/…` を指すと、転送を通らず手元のマシンの `localhost` として開きます。そのときはアドレス欄に打ち直してください。
- パスキー（WebAuthn。1Password に保存したものなど）は欄では使えません。GUI の web view（Linux は WebKitGTK、macOS は WKWebView）が任意のサイトに提供しないためです。欄の ↗ ボタンでそのページを手元のブラウザで開き直し、そちらでパスキーを使ってください。リモートの開発サーバーのページは欄の ssh 転送越しに開くので、欄を開いているあいだは見られます。
