# :コマンド一覧

Helix モードのノーマルモードで `:` を押すと、コマンドを入力できます。
VS Code モードでは、コマンドパレット（`F1`）から同じ操作ができます。

## ファイルとバッファ

| コマンド | 別名 | 動作 |
| --- | --- | --- |
| `:w [パス]` | `:write` | 保存。パスを付けるとそのパスに保存 |
| `:wa` | `:write-all` | すべて保存 |
| `:q` | `:quit` `:qa` | 終了。未保存のファイルがあれば止める |
| `:q!` | `:quit!` `:qa!` | 保存せずに終了 |
| `:wq` | `:x` | 保存して終了 |
| `:wqa` | `:xa` | すべて保存して終了 |
| `:o <パス>` | `:open` `:e` `:edit` | ファイルを開く |
| `:n` | `:new` | 新しいファイル |
| `:bc` | `:bclose` `:buffer-close` | バッファを閉じる |
| `:bc!` | `:bclose!` `:buffer-close!` | 保存せずにバッファを閉じる |
| `:reload` | `:rl` | ディスクから読み直す |
| `:<行番号>` | — | その行へ移動 |

## 編集と LSP

| コマンド | 別名 | 動作 |
| --- | --- | --- |
| `:fmt` | `:format` | 整形 |
| `:lsp-restart` | — | 言語サーバーを再起動 |

## 検索と置換

| コマンド | 別名 | 動作 |
| --- | --- | --- |
| `:grep [-x 除外] [-i 包含] <文字列>` | `:rg` | 検索・置換の窓を開く（検索欄に文字列を入れる） |
| `:replace [-x 除外] [-i 包含] <文字列> => <置換後>` | `:rep` | 検索・置換の窓を開く（検索欄と置換欄に入れる） |

## 表示

| コマンド | 別名 | 動作 |
| --- | --- | --- |
| `:preview` | `:md` | Markdown プレビューの切替（並べて表示 → 全幅 → 閉じる） |
| `:tree` | `:explorer` | ファイルツリーへ移動 |
| `:sh [コマンド]` | `:run` `:!` | ターミナルでコマンドを実行。省略するとターミナルの表示切替 |

## 差分モード

| コマンド | 動作 |
| --- | --- |
| `:gitdiff [on\|off\|split\|unified]` (`:gd` `:review`) | 差分モード（比較元 `HEAD`）の切替、分割 / 統合の切替 |
| `:pr [番号]` | 差分モードでプルリクエストの base と比べる。番号を省略すると一覧から選ぶ |

## ブラウザ

| コマンド | 別名 | 動作 |
| --- | --- | --- |
| `:browser forward <対象ポート> [待ち受けポート]` | — | ポート転送を始める |
| `:browser list` | — | ポート転送の一覧 |
| `:browser stop <待ち受けポート>` | — | ポート転送を止める |
| `:open-url [URL]` | `:browse` | 外部ブラウザで開く。省略するとカーソル位置の URL |

## エージェント

| コマンド | 動作 |
| --- | --- |
| `:agent` | 提案パネルへ移る / 閉じる |
| `:agent cancel` | エージェントの作業を中止する |
| `:agent stop` | エージェントを止める |

## 設定

| コマンド | 動作 |
| --- | --- |
| `:theme [名前]` | テーマを切り替える。省略すると一覧 |
| `:keymap [helix\|vscode]` | 操作の方式を切り替える |
| `:config-reload` | 設定ファイルを読み直す |
