An IDE that lives in your terminal

shijimi-editor puts a file tree, tabs, LSP, a diff view and a terminal panel on one screen, laid out like VS Code. Edit with Helix-style modal keys or with VS Code-style keys. The command is shj.

Install Read the manual GitHub

Review changes as whole files

Space G (or Ctrl+G) switches the whole editor to diff mode against HEAD. Space g compares with the base of a pull request.

  • Changed files are listed in CHANGES
  • A changed file opens as the whole file, split or unified
  • The right side is editable, so you can fix things while you review

LSP out of the box

Diagnostics, completion, hover, go to definition, references, rename, code actions and formatting. gopls, rust-analyzer, typescript-language-server and others are set up by default.

  • Configured with a languages.toml that is compatible with Helix's

Markdown preview beside the source

Space m shows the rendered Markdown next to the buffer you are editing. Press it again to show only the preview.

  • Headings, lists, tables, code and quotes
  • Mermaid diagrams and images in terminals with the Kitty graphics protocol

A terminal panel at the bottom

Ctrl+` opens a terminal under the editor. Run tests and servers without leaving the editor, and open several in tabs.

  • Claude Code running there can read your selection and send you changes as diffs to approve

And more

Two ways to edit

Helix-style normal / insert / select modes with multiple cursors, or modeless VS Code-style keys.

Find anything

Quick Open, a command palette and search and replace across the whole project.

Suggestions panel

Suggests the next step from git, LSP and the terminal, and asks an agent over ACP when you pick one.

File tree with Git status

Modified, untracked and added files are marked in the tree.

Single-file mode

shj file opens just that file and exits on :wq, so it works as your $EDITOR.

English and Japanese

The UI and the manual are available in both languages.

Install

nix run github:mm1995tk/shijimi-editor/release   # run it right away
nix profile install github:mm1995tk/shijimi-editor/release
go install github.com/mm1995tk/shijimi-editor/cmd/shj@latest

Then run shj in your project. See Installation and startup in the manual for details.
